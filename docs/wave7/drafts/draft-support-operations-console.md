# [DRAFT] Support Operations Console

**Wave:** 8 (Planned)  
**Status:** DRAFT

## Overview

A dedicated console for support agents to manage governed operations.

## Proposed Features

- **Unified Lookup:** Search across all actor domains.
- **Governed Impersonation UI:** One-click impersonation with mandatory reason input.
- **Escalation Workflow:** Request platform admin approval for sensitive actions.
- **Audit View:** Real-time view of support-related security events.
